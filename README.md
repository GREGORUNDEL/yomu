# yomu 読む

Интерактивная читалка японских текстов для iPhone (PWA на GitHub Pages).

Тексты лежат в приватном репозитории и размечены заранее: каждое слово знает свою
словарную форму, чтение, перевод и форму, каждое предложение — перевод и разбор.
Нажатие на слово показывает окошко с объяснением, «Разбор» — всё предложение по частям.
Слова можно сохранять в словарь и выгружать в TSV/CSV.

Спецификация и формат данных — в `CLAUDE.md`. Проверка — `python3 tests/check.py`.
