# yomu (読む) — интерактивная читалка японских текстов

Владелец: GREGORUNDEL. Общение на русском. iPhone 14 Pro Max.

## Принцип
Тексты Claude НЕ генерирует. Пользователь присылает готовый текст, Claude размечает его
в формат ниже и кладёт в приватный репозиторий `GREGORUNDEL/yomu-texts`
(файл `texts/<id>.json` + строка в `index.json`).
Этот репозиторий (`yomu`) публичный — только код, никаких текстов и личных данных.

## Платформа
PWA для iPhone на GitHub Pages (как «Копилка»), открывается с иконки на «Домой».
Без сборки: `index.html` + `css/app.css` + `js/*.js` (общая глобальная область, грузятся по порядку).
Данные — из `yomu-texts` через GitHub API с fine-grained токеном
(Contents: Read and write только на `yomu-texts`). Токен вводится в настройках приложения,
в чат его не присылают.

## Дизайн
- Apple HIG (шкала шрифтов, отступы, системные элементы), как в «Копилке».
- Цвета читалки: бумага/папирус (фон), тёмно-коричневый текст, охра — акцент.
  Тёмная тема — тёмная сепия, автоматически по настройке iPhone.
- Шрифт текста — системный Hiragino Sans; в настройках можно переключить на Hiragino Mincho.
  Интерфейс — SF Pro.
- Стеклянные элементы (окошко слова, панель, кружок настроек) — размытие, как в iOS 26.

## Экраны и жесты
1. **Тексты** — список. Название на японском и на русском, источник, тонкая полоса прогресса.
2. **Словарь** — сохранённые слова: только словарная форма + перевод.
3. **Читалка** — открывается из списка как отдельный экран.

- Сверху на «Тексты»/«Словарь» — сегментный переключатель «Тексты | Словарь»; кликабельный,
  но основной способ — свайп влево/вправо по экрану.
- Кружок настроек — внизу справа, только на «Тексты» и «Словарь».
- В читалке ТОЛЬКО текст: нет заголовка, кнопок, кружка. Небольшой отступ сверху под
  системным размытием статус-бара. Назад — только свайпом от левого края экрана
  (зона ~20px у края); остальное касание — прокрутка/выбор слов.
- Читалка запоминает место; текст открывается там, где остановился.

## Настройки (всё только здесь)
Фуригана вкл/выкл · размер текста · шрифт Sans/Mincho · направление: 横書き (строки слева
направо) / 縦書き (столбцы справа налево, прокрутка вбок) · GitHub (токен).

## Словарь
- Экспорт — прямо в словаре (кнопка рядом с поиском): весь словарь или выбранные слова.
- Выбор как в iOS: зажать слово → режим выбора с галочкой; не отпуская, вести вверх/вниз —
  отмечаются все пройденные (у краёв экрана список сам прокручивается). Дальше — нажатием.
  Внизу вместо кружка настроек панель: Готово · Выбрано N · Все/Снять · удалить · экспорт.
- Удаление одного слова — свайпом влево (вне режима выбора).

## Взаимодействие в тексте
- Текст абзацами как в оригинале, предложения НЕ с новой строки.
- Единица нажатия — слово целиком со спряжением (食べています — одна единица), частицы отдельно.
- Слово → маленькое стеклянное окошко рядом со словом: словарная форма (кандзи + кана),
  перевод, какая форма использована — коротко. Пока окошко открыто, предложение подсвечено.
  Кнопки: «+ в словарь», «Разобрать предложение».
- Разбор → нижняя панель (~полэкрана): перевод целиком, затем составляющие с объяснением;
  у составляющих-слов тоже есть «+ в словарь».
- В 縦書き: числа из 2 цифр ставятся горизонтально в клетку, окошко слова — сбоку от столбца.
- Окошко никогда не закрывает выбранное слово (при нехватке места текст прокручивается) и не
  заходит в верхнюю зону под системным размытием (safe-top + 40px); слова в этой зоне не нажимаются.
- Связь с Анки не нужна (решено 2026-10-26). Экспорт словаря — для будущих карточек.

## Формат данных (yomu-texts)
`index.json`: `[{ "id", "ja", "ru", "source", "added" }]` — ja/ru — название на двух языках.

`texts/<id>.json`:
```json
{
  "id": "...", "ja": "...", "ru": "...", "source": "...",
  "paragraphs": [
    [ { "id": "s1",
        "tokens": [
          { "t": "食べています", "fu": [["食","た"],["べています",null]],
            "b": "食べる", "br": "たべる", "g": "есть, кушать",
            "f": "て-форма + います: действие в процессе", "p": "глагол" },
          { "t": "を", "g": "частица объекта", "p": "частица" },
          { "t": "。", "punct": true }
        ],
        "tr": "перевод предложения",
        "parts": [ { "j": "фрагмент", "e": "объяснение",
                     "b": "словарная форма", "br": "чтение", "g": "перевод" } ] } ]
  ]
}
```
- `t` — как в тексте (склейка всех `t` предложения = исходное предложение без изменений).
- `fu` — сегменты для фуриганы, только если в слове есть кандзи (null = без чтения).
- `b`/`br` — словарная форма и её чтение (`br` только если `b` содержит кандзи; если `b`
  не указан — словарная форма совпадает с `t`). `g` — перевод. `f` — форма (пусто для простых).
  `p` — часть речи. `punct` — знак препинания, не нажимается. `{"t":"\n","punct":true}` — перенос
  строки из оригинала (только где книга разбивает фразу без знака препинания, напр. стихи, детские книги).
- `parts[].b/br/g` — только у составляющих, которые являются словом (их можно добавить в словарь).

`vocab.json` — словарь пользователя (пишет приложение):
`[{ "b", "br", "g", "s", "textId", "sentenceId", "added" }]` — `s` — предложение-источник.
Ключ слова — `b` + `br`. Экспорт: TSV (для Анки) и CSV (для Excel, UTF-8 с BOM),
колонки: слово, чтение, перевод, предложение, текст.
