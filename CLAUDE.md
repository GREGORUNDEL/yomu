# yomu (読む) — интерактивная читалка японских текстов

Владелец: GREGORUNDEL. Общение на русском.

## Принцип
Тексты Claude НЕ генерирует. Пользователь присылает готовый текст, Claude размечает его
в формат ниже и кладёт в приватный репозиторий `GREGORUNDEL/yomu-texts`.
Этот репозиторий (`yomu`) публичный — только код, никаких текстов и личных данных.

## Платформа
PWA для iPhone на GitHub Pages (как «Копилка»). Данные — из `yomu-texts` через GitHub API
с fine-grained токеном (вводится в приложении, в чат не присылается).

## Экраны
1. **Тексты** — список текстов. Нажатие → отдельный экран чтения.
2. **Экран чтения** — текст абзацами как в оригинале, предложения НЕ с новой строки.
3. **Словарь** — слова, сохранённые из текстов.

## Взаимодействие в тексте
- Единица нажатия — слово целиком вместе со спряжением (食べています — одна единица),
  частицы отдельно.
- Нажатие на слово → маленькое стеклянное окошко рядом со словом (не на весь экран):
  словарная форма (кандзи + кана), перевод, какая форма использована — коротко.
  Пока окошко открыто, предложение подсвечено.
- В окошке: кнопка «Разобрать предложение» и кнопка «+ в словарь».
- Разбор предложения → нижняя панель (~полэкрана): перевод целиком, затем разбор
  на составляющие с объяснением каждой.
- Фуригана: переключатель вкл/выкл.
- Связь с Анки не нужна (решено 2026-10-26).

## Формат данных (yomu-texts)
`index.json` — список: `[{ "id", "title", "source", "added" }]`

`texts/<id>.json`:
```json
{
  "id": "...", "title": "...", "source": "...",
  "paragraphs": [
    [ { "id": "s1",
        "tokens": [
          { "t": "食べています", "fu": [["食","た"],["べています",null]],
            "b": "食べる", "br": "たべる", "g": "есть, кушать",
            "f": "て-форма + います: действие в процессе", "p": "глагол" },
          { "t": "。", "punct": true }
        ],
        "tr": "перевод предложения",
        "parts": [ { "j": "фрагмент", "e": "объяснение" } ] } ]
  ]
}
```
- `t` — как в тексте; `fu` — сегменты для фуриганы (null = без чтения);
  `b`/`br` — словарная форма и её чтение; `g` — перевод; `f` — форма (пусто для простых);
  `p` — часть речи.

`vocab.json` — словарь пользователя (пишет приложение):
`[{ "b", "br", "g", "t", "textId", "sentenceId", "added" }]`
